Kurako for Windows

Kurako is a cross-platform local anime library and video player. Its interface is built with Flutter, while Rust provides reusable core functionality.

Main features

- Scan local folders, Windows/NAS SMB shares, and WebDAV servers.
- Match titles with Bangumi metadata, ratings, tags, and collection status.
- Play videos and external subtitles with the built-in player, and manage videos and subtitles downloaded to this computer.
- Use the same media-library and player workflow across Windows, Android, and Apple platforms.

Installation and updates

1. A later page lets you choose the Kurako installation folder.
2. Desktop and Start Menu shortcuts are optional tasks and are disabled by default.
3. A newer version can be installed over the existing folder without clearing media-library settings.
4. Program files go into the selected installation folder. The database, account settings, network credentials, and default downloads are stored under Documents\KURAKO.
5. Uninstalling Kurako does not delete Documents\KURAKO. To remove all local data, first use the cleanup actions on Kurako's Maintenance page, then inspect that folder manually.

System and network requirements

- 64-bit Windows 10 or Windows 11.
- SMB and WebDAV require network access to the Windows or NAS server, valid credentials, and permission to access the selected directories.
- Bangumi login opens the default browser and returns to Kurako through the kurako:// callback. Allow the browser to open Kurako when prompted.
- If Windows Firewall or security software asks for network access, grant only the access appropriate for the local network being used.
