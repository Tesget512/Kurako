Kurako Windows 安装说明

Kurako 是一款面向本地番剧收藏的跨平台媒体库与视频播放器，使用 Flutter 构建界面，并由 Rust 提供跨平台核心能力。它可以扫描本地文件夹或 SMB 网络共享、匹配 Bangumi 番剧资料、使用内置播放器播放视频，并管理下载到本机的 SMB 视频与字幕。

安装说明

1. 下一步可以选择 Kurako 的安装目录。
2. 桌面快捷方式和开始菜单快捷方式均为可选附加任务。
3. 安装新版本时可以直接覆盖原目录，不会清空媒体库配置。
4. Kurako 的数据库、账号设置与默认下载内容保存在“文档\KURAKO”，不放在程序安装目录中。
5. 卸载 Kurako 默认不会删除“文档\KURAKO”中的媒体库数据和下载文件，便于重装后继续使用。如需彻底清理，请先在软件设置中使用对应的清理功能，再手动检查该目录。

运行要求

- 64 位 Windows 10 或 Windows 11。
- Bangumi 登录会使用系统默认浏览器，并在授权完成后通过 kurako:// 回到 Kurako。浏览器首次回调时如询问是否打开 Kurako，请选择允许。
- SMB 功能需要设备能够访问同一局域网中的 Windows 或 NAS 共享，并拥有有效的共享账号与权限。

本安装包不会捆绑修改浏览器、系统代理或其他无关软件。
