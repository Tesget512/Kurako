Kurako Windows 安装说明

Kurako 是一款面向本地番剧收藏的跨平台媒体库与视频播放器，使用 Flutter 构建界面，并由 Rust 提供跨平台核心能力。

许可证简要说明

Kurako 原创代码采用 GNU General Public License v3.0 only（GPL-3.0-only）。完整许可证附在本页安装说明下方，并随程序安装到 docs 目录；第三方组件继续适用各自的许可证。

主要功能

- 扫描本地文件夹、Windows/NAS 的 SMB 共享与 WebDAV 服务器。
- 使用 Bangumi 匹配番剧资料、评分、标签与收藏状态。
- 使用内置播放器播放视频与外挂字幕，并管理下载到本机的视频和字幕。
- 同一套媒体库和播放器体验覆盖 Windows、Android 与 Apple 平台。

安装与更新

1. 后续页面可选择 Kurako 的安装目录。
2. 桌面快捷方式与开始菜单快捷方式均为可选附加任务，默认不创建。
3. 安装新版本时可直接覆盖原安装目录；安装程序不会清空媒体库配置。
4. 程序文件放在所选安装目录，数据库、账号设置、网络凭证与默认下载内容保存在“文档\Kurako”。
5. 卸载 Kurako 默认不会删除“文档\Kurako”中的媒体库数据和下载文件。如需彻底清理，请先使用软件“维护”页面中的清理功能，再手动检查该目录。

运行与网络要求

- 64 位 Windows 10 或 Windows 11。
- SMB 与 WebDAV 功能要求当前电脑能访问对应 Windows/NAS 服务器，并拥有有效的地址、账号、密码与目录权限。
- Bangumi 登录会打开系统默认浏览器，并在授权完成后通过 kurako:// 回到 Kurako。浏览器首次询问是否打开 Kurako 时，请选择允许。
- Windows 防火墙或安全软件如询问网络访问权限，请仅按实际使用的局域网环境授权。

本安装包不会捆绑其他软件，也不会主动修改浏览器、系统代理或其他无关系统设置。
